## Canada Simulator — metro intelligence layer
The simulator now includes 17 major Canadian metropolitan profiles with a shared local-intelligence schema. Metro panels request Statistics Canada CMA-level population (17-10-0148-01), labour force (14-10-0459-01), building permits (34-10-0292-01), and CMHC housing starts (34-10-0156-01) where that geography is available. Local Atlas events and nearby reference infrastructure are spatially filtered around the selected metro. City Pulse and city projections are Atlas-derived scenario outputs and are explicitly labelled as such.
